# The competition itself

What's actually on the official Prom Virgo Challenge Devpost page
(https://virgo.devpost.com), fetched 2026-09-05. Devpost pages are
JS-rendered, so this is a fetched-and-read summary, not a copy of the raw
page — treat the flagged item below as something to confirm directly on the
live page before relying on it, not settled fact.

## Deadline

**September 19, 2026, 11:45pm EDT / 11:59pm** (the page states both times in
different places — see the flag below). No extensions, per the page's own
wording ("Projects should be submitted by 11:59 PM (NO EXTENSIONS)"). As of
this write-up (2026-09-05), that's about two weeks out.

## Judging (100 points total)

- **Educational Impact — 25 pts**: "How effectively does the tool solve a
  real problem in education?"
- **Creative Use of AI/ML — 25 pts**: "How clever and meaningful is the
  integration of machine learning?"
- **Technical Execution — 25 pts**: "Is the application functional, stable,
  and intuitive to use?"
- **The Pitch & Demo — 25 pts**: "How well did the team communicate their
  vision?"

Matches the criteria already assumed in this project's other docs
(ARCHITECTURE.md, EVALUATION.md) — nothing here changes prior decisions.

## Submission requirements

- A demo video, **hard-capped at 2 minutes** — the page states content past
  that won't be reviewed by judges, not just discouraged.
- Source code (a GitHub repository or equivalent).

## Team / eligibility

- Solo or teams up to 4.
- Ages 13+, students only, no companies/professional organizations, open to
  all countries/territories with standard exclusions.

## Prizes

1st: $1,000 · 2nd: $400 · 3rd: $100 · 4th-5th: certificate · 6th-10th:
honorable mention.

## Flag — an internal inconsistency on the official page worth confirming directly

Two separate reads of the page surfaced conflicting phase dates:

- One part of the page: *"August 31th - The challenge starts!"*
- Another part (an originality/rules note): *"All code must be written
  during the hackathon window (August 17th – 29h)."*

Read literally, the "challenge starts" date is **after** the stated coding
window ends, which doesn't parse as a real sequence of events. This is most
likely sloppy copy on a templated Devpost timeline widget (a generic
"phases" section with dates that weren't fully updated for this specific
challenge), not a real, currently-enforced rule that submissions must have
been coded entirely within August 17-29 — but this project's other docs and
this loop's own commit history assume ongoing development through
mid-September is fine, so **this is worth confirming directly on the live
Devpost page (or with the organizers) before submitting**, rather than
resolving it one way or the other here. Flagging it rather than guessing, per
this project's own "never fabricate, say so if something can't be verified"
standard (see EVALUATION.md).

No other rules content addressed AI-coding-assistant policy, disqualification
criteria, or IP/licensing specifics as of this fetch — if those matter, they'd
